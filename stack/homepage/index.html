Farfield OS

An opinionated home-server bootstrap for Arch Linux.

Run it → source
What this is

One script turns a fresh Arch install into a server managed over SSH — hardened shell, the usual runtimes, and an ingress stack (Tailscale, Caddy, Cloudflare Tunnel) that keeps the public surface opt-in. It's the box behind farfield.systems.

Inside
Ingress
Tailscale in, Caddy for HTTPS, Cloudflare Tunnel for the public bits. add-site and friends manage the Caddyfile.
Shell
Zsh + Spaceship, tmux by default, ripgrep / fzf / eza / zoxide / bat.
Dashboard
Six live panels on an attached display, touch included. ff-dashboard draws the same board over SSH.
Runtimes
Node, Python (uv), Ruby, Rust, Go, Java, Docker, PostgreSQL, Valkey.
Snapshots
Btrfs + Snapper around every pacman transaction. Bad update → boot yesterday's snapshot.
Security
UFW, Fail2ban, hardened SSH.
Agent
Claude Code on the host, with system context in ~/CLAUDE.md.
Run it

MIT. Every default is a decision I made for my own machine — no wizard, no knobs. Fork it if you want different decisions.

You'll need a fresh Arch install, a sudo user, and SSH. Public sites want a domain on Cloudflare; private access wants Tailscale. Read setup.sh before you run it.

git clone https://github.com/iammatthias/farfield-os.git
cd farfield-os
sudo ./scripts/setup.sh
sudo reboot
# then ff-bootstrap walks the one-time auth steps
